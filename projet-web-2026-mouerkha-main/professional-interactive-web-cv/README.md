# Professional Interactive Web CV

This project is a professional interactive web CV built using React and Vite, integrated with jQuery for DOM manipulation and animations. The application showcases various sections including a header, about, projects, and contact form.

## Installation

1. Clone the repository:
   ```
   git clone <repository-url>
   cd professional-interactive-web-cv
   ```

2. Install dependencies:
   ```
   npm install
   ```

3. Start the development server:
   ```
   npm run dev
   ```

## Features

- **Responsive Design**: The CV is designed to be responsive using CSS Flexbox/Grid.
- **jQuery Integration**: Utilizes jQuery for animations and DOM manipulation.
- **Project Cards**: Displays individual project cards with hover effects.
- **Contact Form**: Includes a contact form with validation.

## Usage

- Navigate through the sections of the CV to view the information.
- Hover over project cards to see the scaling effect.
- Fill out the contact form to get in touch.
